# Система отзывов товаров (Product Reviews)

## Что это

Добавление системы отзывов на страницу товара в клиентском приложении Astrum (Next.js). Пользователи могут оставлять отзывы **после покупки**, с рейтингом по критериям, фотографиями и модерацией. Встроен ML-анализ тональности отзыва.

## Контекст

Монополия Astrum: 3 сервиса (API-astrum, auth-astrum, customer). PostgreSQL + Prisma.

## Core Value

Пользователь после покупки может оставить детальный отзыв с оценкой по критериям, фото и текстом. Отзыв проходит модерацию и ML-анализ тональности перед публикацией. Продавец может ответить.

## Ключевые решения

| Решение | Обоснование | Статус |
|---------|-------------|--------|
| ML-анализ тональности | Подготовка к нейросети, сейчас заглушка | — Pending |
| Модерация перед публикацией | Контроль качества контента | — Pending |
| Фото в отзывах | Пользователи хотят показывать реальный товар | — Pending |
| Ответ продавца | Обратная связь от бизнеса | — Pending |
| Критерии: Качество, Доставка, Соответствие | Детализированная оценка вместо одной звезды | — Pending |

## Требования

### Validated

(Пока нет — строим с нуля)

### Active

- [ ] Пользователь может оставить отзыв после покупки
- [ ] Отзыв включает рейтинг 1-5 звёзд + 3 критерия (качество, доставка, соответствие)
- [ ] Отзыв включает текстовый комментарий
- [ ] Пользователь может прикрепить фото к отзыву
- [ ] Отзыв проходит модерацию перед публикацией
- [ ] ML-анализ тональности: заглушка (Положительный/Отрицательный)
- [ ] Продавец может ответить на отзыв
- [ ] Отображение отзывов на странице товара
- [ ] Средняя оценка и распределение по звёздам на странице товара

### Out of Scope

- Редактирование/удаление отзыва пользователем — в следующей версии
- Публичные отзывы без модерации — контроль качества
