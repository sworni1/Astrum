# FEATURES: ML-анализ отзывов

**Date:** 2026-04-08

## Table Stakes (must have, иначе пользователи не примут)

### 1. Классификация отзыва при создании
- При создании отзыва текст отправляется в ML-сервис для анализа
- Результат (positive/negative/neutral) сохраняется в Review
- Задержка должна быть < 500ms, либо async через очередь

### 2. Отображение тональности отзыва на странице товара
- Бейдж/метка рядом с каждым отзывом: "👍 Положительный" / "👎 Отрицательный"
- Адаптировано под русский язык UI

### 3. Агрегированная статистика по товару
- Процент положительных/отрицательных отзывов
- Обновляется при каждом новом отзыве

### 4. Секция отзывов на странице товара
- Отзывы с рейтингами, комментарием, фото
- Форма написания отзыва (для тех, кто купил)
- Пагинация или бесконечный скролл

## Differentiators (competitive advantage)

### 5. Фильтрация отзывов по тональности
- Показать только положительные / только отрицательные
- Визуальный toggle в UI

### 6. Тренды тональности по времени
- График: как меняется настроение отзывов со временем
- Полезно для админ-панели

### 7. Confidence score
- Показать уверенность модели рядом с лейблом
- Низкий confidence → пометить как "не определено"

### 8. Admin: Dashboard аналитики отзывов
- Общая статистика, тренды, проблемные товары
- Top negative sentiment products

### 9. Ручное переобучение модели
- Endpoint для запуска переобучения на новых данных
- Импорт датасетов из CSV/Excel

## Anti-features (what NOT to build)

### 10. Aspect-based sentiment analysis
- Слишком сложно для прототипа — отдельный проект
- Требует размеченных данных по аспектам

### 11. Реалтайм-стриминг анализа
- WebSocket для показа анализа в реальном времени — overkill
- REST достаточно

### 12. Анализ тональности изображений
- Компьютерное зрение — отдельная система
- Фокус только на тексте отзыва

### 13. Модерация контента через ML
- Классификация оскорблений/спама — отдельная задача
- Не смешивать с тональностью
