# Requirements: Astrum ML-анализ отзывов

**Defined:** 2026-04-08
**Core Value:** Каждый отзыв анализируется автоматически — пользователь и администратор сразу видят агрегированную тональность по товару.

## v1 Requirements

### ML-инфраструктура

- [ ] **MLE-01**: Python-сервис на FastAPI с endpoint `/api/sentiment` для классификации текста
- [ ] **MLE-02**: Обученная TF-IDF + Naive Bayes модель для анализа тональности
- [ ] **MLE-03**: Модель сериализована через joblib, загружается при старте сервиса
- [ ] **MLE-04**: Docker-контейнер для Python-сервиса в docker-compose

### Интеграция

- [ ] **INT-01**: Express вызывает ML-сервис при создании отзыва (async)
- [ ] **INT-02**: Поля `sentiment` и `sentimentScore` добавлены в модель Review (Prisma)
- [ ] **INT-03**: Бэкфил-скрипт для анализа существующих отзывов без sentiment
- [ ] **INT-04**: Graceful degradation при недоступности ML-сервиса

### Визуализация на странице товара

- [ ] **UI-01**: Секция отзывов отображается на странице товара
- [ ] **UI-02**: Бейдж тональности (👍/👎) рядом с каждым отзывом
- [ ] **UI-03**: Агрегированная статистика: процент положительных/отрицательных отзывов по товару
- [ ] **UI-04**: Фильтрация отзывов по тональности (положительные / отрицательные / все)

## v2 Requirements (deferred)

- **MLE-05**: Переобучение модели через HTTP endpoint
- **MLE-06**: Пайплайн автоматического переобучения по расписанию
- **ANA-01**: Dashboard аналитики отзывов для админа (тренды, проблемные товары)
- **ANA-02**: Тренд-график тональности по времени
- **ANA-03**: Confidence score с визуализацией
- **ANA-04**: Ручная коррекция тональности пользователем / репорт об ошибке

## Out of Scope

| Feature | Reason |
|---------|--------|
| Анализ изображений в отзывах | Компьютерное зрение — отдельная система |
| Aspect-based sentiment | Требует размеченных данных, слишком сложно для прототипа |
| BERT / Transformers | TF-IDF достаточно для прототипа, Transformers слишком тяжелы |
| Модерация контента через ML | Отдельная задача, не смешивать с тональностью |
| Реалтайм WebSocket для анализа | REST достаточно |
| Внешний LLM API | Целевой подход — self-hosted ML |
